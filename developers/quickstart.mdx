<Steps>
  <Step title="Get an API key">
    During the beta, API keys are issued by the Fabriq team. Keep your key secret: it identifies you for rate limits.
  </Step>
  <Step title="Fetch the top trending pools">
    <CodeGroup>

    ```bash cURL
    curl "https://public-api.fabriq.trade/v1/trending/pools?limit=5" \
      -H "X-API-Key: $FABRIQ_API_KEY"
    ```

    ```javascript JavaScript
    const response = await fetch(
      "https://public-api.fabriq.trade/v1/trending/pools?limit=5",
      { headers: { "X-API-Key": process.env.FABRIQ_API_KEY } }
    );
    const { data, meta } = await response.json();
    for (const pool of data) {
      console.log(pool.rank, `${pool.base.symbol}/${pool.quote.symbol}`, pool.fab_score);
    }
    ```

    ```python Python
    import os
    import requests

    response = requests.get(
        "https://public-api.fabriq.trade/v1/trending/pools",
        params={"limit": 5},
        headers={"X-API-Key": os.environ["FABRIQ_API_KEY"]},
    )
    for pool in response.json()["data"]:
        print(pool["rank"], f'{pool["base"]["symbol"]}/{pool["quote"]["symbol"]}', pool["fab_score"])
    ```

    </CodeGroup>
  </Step>
  <Step title="Read the response">
    Every response has the same shape: the result in `data`, and freshness and paging details in `meta`.

    ```json
    {
      "data": [
        {
          "rank": 1,
          "address": "5rCf1DM8LjKTw4YqhnoLcngyZYeNnQqztScTogYHAS6",
          "dex": "meteora_dlmm",
          "base": { "mint": "So11111111111111111111111111111111111111112", "symbol": "SOL", "side": "x" },
          "quote": { "mint": "EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v", "symbol": "USDC", "side": "y" },
          "liquidity_usd": 1338416.3,
          "fab_score": 18.42,
          "stats": { "h1": { "volume_usd": 2841120.5, "lp_fees_usd": 1136.45, "apr_pct": 0.17 } }
        }
      ],
      "meta": { "as_of": "2026-11-08T14:02:11Z", "indexed_slot": 478213990 }
    }
    ```

    Pools are shown as **base** and **quote** tokens. See [Prices and valuation](/developers/concepts/prices-and-valuation#base-and-quote) for how Fabriq picks them.
  </Step>
</Steps>
