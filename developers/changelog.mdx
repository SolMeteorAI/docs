<Update label="November 2026" description="v1.0 beta">
  First version of the public API.

  - General: `GET /status`, `GET /dexes`.
  - Tokens: search by symbol or name, token profile, batch lookup, USD candles.
  - Pools: list, detail, swaps, liquidity events.
  - Trending: ranked pools with filters, categories.
  - Portfolio: overview with net worth and balances, balances, positions, activity, PnL summary, daily PnL, PnL by pool, LP score.
  - Access: API keys, or [pay per request with x402](/developers/pay-per-request) in USDC on Solana and Base. Requests with neither now answer `402 payment_required` instead of `401`.
  - [MCP server](/developers/mcp) at `/mcp`: twelve read-only tools for AI agents, the concept guides as resources, two prompts. API key (header, or in the URL for the Claude and ChatGPT apps) or x402 per tool call.
</Update>
