---
title: Rate limits
description: How many requests a paying wallet or API key can make, and what to do when you hit the limit.
---

[Pay-per-request](/developers/pay-per-request) callers are limited per paying wallet, and [API keys](/developers/authentication) per key.

| Access | Requests per minute | Requests per day |
| --- | --- | --- |
| x402, per paying wallet | 300 | 100,000 |
| API key | 60 | 50,000 |

Requests without a valid payment or a key are also limited per IP address.

Batch endpoints count as one request: `GET /tokens?mints=...` with 100 mints costs the same as one token. On the [MCP server](/developers/mcp), each tool call counts as one request.

Contact the Fabriq team if you need higher limits.

## Headers

Every response carries your current budget:

| Header | Meaning |
| --- | --- |
| `X-RateLimit-Limit` | Requests allowed in the current window. |
| `X-RateLimit-Remaining` | Requests left in the current window. |
| `X-RateLimit-Reset` | Seconds until the window resets. |

## When you hit the limit

The API answers `429 rate_limited` with a `Retry-After` header in seconds. Wait that long before retrying. A rate-limited request isn't charged: payments settle only on success.

```javascript
// fetchWithPayment is the x402-wrapped fetch from the Quickstart
async function fabriq(path) {
  for (let attempt = 0; attempt < 5; attempt++) {
    const response = await fetchWithPayment(`https://api.fabriq.trade/v1${path}`);
    if (response.status !== 429) {
      return response.json();
    }
    const wait = Number(response.headers.get("Retry-After") ?? 1);
    await new Promise((resolve) => setTimeout(resolve, wait * 1000));
  }
  throw new Error("Rate limited");
}
```

## Using fewer requests

- Batch token lookups with `GET /tokens?mints=...` (up to 100 mints).
- Match your polling interval to the data refresh rate. Trending scores update every second, 24-hour stats every 10 seconds, and LP score ranks every hour. See [API status](/api-reference/general/get-api-status).
- Use `GET /portfolio/{wallet}` for a wallet's summary (net worth, top balances, open positions, PnL) instead of combining several calls.
