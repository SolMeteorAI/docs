## Sources

| Data | Source |
| --- | --- |
| Swaps, deposits, withdrawals, claims, pool creations | Fabriq's indexer, decoding each DEX's programs from finalized blocks |
| USD and SOL values, token prices | Fabriq's valuation of every swap (see [Prices and valuation](/developers/concepts/prices-and-valuation)) |
| Token supply, open position holdings, unclaimed fees, balances | On-chain accounts, read by Fabriq |
| Token identity, holders, organic score, audit flags | Jupiter |
| Dexscreener boosts and profile, older pool creation dates | Dexscreener |
| Token categories (stocks, LSTs, stablecoins…) | A curated token catalog |

Jupiter's and Dexscreener's data are kept apart. The one exception: when Jupiter has no name or symbol for a token, the API shows Dexscreener's.

## Commitment

Everything comes from **finalized** blocks, so data never rolls back. Indexed data usually trails the chain tip by 2 to 3 seconds. `GET /status` reports the current lag.

## Freshness

| Data | Updates |
| --- | --- |
| Trending scores, 5-minute and 1-hour pool stats, prices of active pools | Every second |
| 6-hour and 24-hour stats, makers, price changes, token holders and organic score | Every 10 seconds |
| A new pool | Listed about 12 seconds after its creation; its token's name, logo, holders and FDV about 2 seconds later |
| Token supply | Within 5 seconds of a token's first swap, then every minute while it trades |
| Token identity and audit (Jupiter) | Every minute for tokens that traded in the last 5 minutes |
| Token categories | Every hour |
| Open positions (holdings, unclaimed fees, range) | Read on chain at request time |
| Closed positions and PnL | As soon as the closing block is indexed |
| LP score ranks | Every hour |
| All-time LP scores | Rebuilt daily after UTC midnight |

## History

Fabriq indexes every slot and has imported historical blocks for all 11 DEXes. Data that depends on history has these limits:

- **Positions opened before the indexed history** are shown when they were used since, but their PnL is `null` and `history_complete` is `false`: Fabriq doesn't know what was deposited.
- **Positions untouched since before the indexed history** don't appear in portfolios. Fabriq only shows positions it has seen act.
- **Pool creation dates** come from the decoded creation, else from Dexscreener. `null` when neither knows.

## Retention

| Data | Kept |
| --- | --- |
| Swaps (`GET /pools/{address}/swaps`) | 7 days |
| 1-second candles | 7 days |
| Candles from 15 seconds to 1 month | The whole indexed history |
| Liquidity events, positions, PnL | The whole indexed history |
