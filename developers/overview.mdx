The Fabriq API gives you programmatic access to pool, swap, token, and LP position data across 11 Solana programs. Fabriq indexes finalized blocks and values positions in USD and SOL.

## Why Fabriq data

- **Our own index.** Fabriq indexes every finalized slot itself rather than reselling another provider's feed. Swaps, deposits, withdrawals and claims are decoded from each DEX's own programs.
- **LP-first.** Positions are tracked from open to close, so PnL includes fees and rewards and works across Meteora, Orca, Raydium, PumpSwap, PancakeSwap, Byreal and Heaven.
- **Live.** Trending scores and 5-minute stats move every second. Indexed data trails the chain by a few seconds.
- **Honest about gaps.** A value Fabriq doesn't know is `null`, never a made-up `0`. Positions opened before the indexed history are flagged instead of showing a wrong PnL.

## Base URL

```text
https://api.fabriq.trade/v1
```

Send an API key in the `X-API-Key` header, or [pay for each request with x402](/developers/pay-per-request). See [Authentication](/developers/authentication).
